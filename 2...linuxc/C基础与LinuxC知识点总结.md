# C 基础与 Linux C 知识点总结

> 本总结由 `1...c_basics` 与 `2...linuxc` 目录下的笔记汇总而成，覆盖 C 语言基础、数组、指针、函数、构造类型、动态内存、Linux 系统命令与开发工具链。

## 一、C 语言基础

### 1.1 计算机与数据表示
- 存储单位：bit（位）< byte（字节）。1B = 8bit；1KB = 1024B，1MB / 1GB / 1TB 依次乘 1024
- 进制表示：二进制(0b)、八进制(0 开头)、十进制、十六进制(0x 开头)
- 进制转换（8421 拆分法）：
  - 二转十：按 2^n 加权求和
  - 二转十六：四位二进制合成一位十六进制
  - 二转八：三位二进制合成一位八进制
- 常用 ASCII：'\0'=0（字符串结束）、'\n'=10（换行）、' '=32（空格）、'0'=48、'A'=65、'a'=97

### 1.2 词法符号与关键字
- 标识符：由数字、字母、下划线组成，开头不能是数字，不能与关键字重名，见名知意
- 32 个关键字分类：
  - 存储类型：auto / static / extern / register
  - 数据类型：int / char / short / long / float / double / signed / unsigned
  - 构造类型：struct / union / enum
  - 选择结构：if / else / switch / case / default
  - 循环结构：for / while / do / goto / break / continue
  - 其他：void / typedef / const / sizeof / volatile / return

运算符：
- 算术：+ - * / % ++ --（/ 整数相除取整；++ 自增）
- 逻辑：&& || !（截断法则：&& 前假则截断、|| 前真则截断）
- 关系：> >= < <= == !=
- 位运算：& 有 0 则 0、| 有 1 则 1、^ 相同为 0 不同为 1、~ 取反、<< 左移、>> 右移
- 三目：表达式1 ? 表达式2 : 表达式3
- 赋值：= += -= *= /=
- 逗号运算符：只取最后一个表达式的结果

运算符优先级（由高到低）：
单目(++ -- ! ~) → 算术(* / + - %) → 移位(<< >>) → 关系(> < >= <= ==) → 位与(&) → 异或(^) → 位或(|) → 逻辑(&& ||) → 条件(?:) → 赋值(=) → 逗号

原码 / 反码 / 补码：计算机用补码存储和计算；正数三码相同；负数反码 = 符号位不变其余取反，补码 = 反码 + 1

### 1.3 数据类型与变量
- 基本类型：int(4字节)、char(1字节)、short(2字节)、long(32位 4 / 64位 8)、float(4字节，6-7位小数)、double(8字节，15-16位小数)
- 变量定义：存储类型 + 数据类型 + 变量名
- 局部变量 vs 全局变量：
  - 定义位置：函数体内 / 函数体外
  - 初值：随机值 / 0
  - 存储：栈区 / 全局区
  - 作用域：本函数 / 整个程序
  - 生命周期：随函数 / 随程序
- 虚拟内存空间布局（自上而下）：内核空间、环境变量、命令行参数、栈、mmap、堆、.bss、.data、常量区、.text

### 1.4 常量
- 整型、浮点型、字符型、字符串（双引号包裹、以 '\0' 结尾）
- 宏常量：#define 宏名 值（纯文本替换，一般大写）

### 1.5 输入输出
- printf：按格式输出，返回值是输出元素个数
- scanf：按格式输入，返回值是正确输入的元素个数
- 格式符：%d %c %f %lf %s %p %o %x（%#o %#x 带前缀）
- m.n：m 位宽、.n 保留 n 位小数
- getchar / putchar：单个字符输入 / 输出
- 垃圾字符回收：scanf 会残留回车等字符，用空格或 %c 前加空格回收

### 1.6 分支语句
- if / else if / else（可嵌套）
- switch(表达式) / case 常量 / default（case 只能跟整型、字符型常量；无 break 会贯穿）

### 1.7 循环语句
- for(表达式1; 表达式2; 表达式3)：初始化、终止条件、修改变量
- while(条件)：先判断后执行
- do...while：先执行后判断
- 嵌套循环：外层改一次，内层执行一轮
- break 结束当前循环；continue 跳过本次；return 结束当前函数

## 二、数组

### 2.1 一维数组
- 定义：数据类型 数组名[元素个数]
- 特点：数据类型相同、内存连续
- 数组名：arr 首地址、&arr 数组指针（整个数组地址）、*arr 首元素值
- 字节大小：len = sizeof(arr) / sizeof(arr[0])
- 初始化：全部初始化、部分初始化（未初始化部分为 0）、未初始化（随机值）
- 清零函数：bzero(void *s, size_t n)、memset(void *s, int c, size_t n)

### 2.2 二维数组
- 定义：数据类型 数组名[行数][列数]
- 数组名：a 首行地址，a+1 次行地址
- 初始化、循环遍历（双层 for）

### 2.3 字符数组与字符串
- 字符串以 '\0' 结尾
- strlen 计算实际元素个数（不含 '\0'）
- sizeof 与 strlen 区别：sizeof 是关键字（编译期），strlen 是函数（运行期）；char arr[]="goto" 时 sizeof=5、strlen=4

### 2.4 排序算法
- 冒泡排序：相邻两两比较，外层 i 控制轮数，内层 j < len-1-i
- 选择排序：每轮选最值放到前面，记录下标 m，最后交换

## 三、指针

### 3.1 指针基础
- & 取地址符、* 取内容符（定义时表示声明指针）
- 定义指针必须初始化，否则产生野指针
- 指针字节大小固定：64 位 8 字节、32 位 4 字节
- 段错误原因：访问不存在的地址、访问系统保护地址、访问只读内存、空指针、堆栈溢出、内存越界

### 3.2 指针运算
- p+n：向高地址移动 n 个数据单位
- p++：向高地址移动 1 个数据单位
- 同一数组中两指针差值 = 相差元素个数

### 3.3 指针与数组
- 数组名是地址常量（不能自增），指针是变量（可以自增）
- 指针与一维数组：a[i] 等价于 *(a+i)，&a[i] 等价于 a+i
- 指针与二维数组：a 是行地址，*a 降级为列地址（元素指针）；a[i][j] 等价于 *(*(a+i)+j)

### 3.4 二级指针
- 一级指针存普通变量地址，二级指针存一级指针地址
- int **q；取值：a = *p = **q；取地址：&a = p = *q

### 3.5 数组指针 vs 指针数组
- 数组指针：本质是指针，指向数组（行指针）int (*p)[3]
- 指针数组：本质是数组，存放地址 int *arr[3]
  - 可存普通变量地址、二维数组首列地址、字符串常量区首地址

### 3.6 const 与 void 指针
- const 修饰普通变量：只读
- const 修饰指针：int const *p（内容不可改，指向可改）、int * const p（指向不可改，内容可改）
- void *：任意类型指针，取元素需强转

### 3.7 大小端
- 大端：低地址存高字节；小端：低地址存低字节
- 例：int a = 0x12345678，小端存储为 78 56 34 12

## 四、函数

### 4.1 函数基础
- 格式：数据类型 函数名(形参列表) { 代码段; return 值; }
- 一次编写多次调用；子函数定义在主函数后需提前声明

### 4.2 函数传参
- 值传递：单向传递，实参不变（形参是实参副本）
- 地址传递：双向传递，可通过指针修改外部变量

### 4.3 指针函数 / 函数指针 / 函数指针数组 / 回调函数
- 指针函数：本质是函数，返回指针（返回的指针需指向静态区 / 全局区 / 堆区，否则函数结束空间被回收）
- 函数指针：本质是指针，指向函数，格式 返回值类型 (*p)(参数列表)
- 函数指针数组：存放函数指针，格式 数据类型 (*arr[n])(参数列表)
- 回调函数：函数指针作为另一个函数的参数

## 五、构造数据类型

### 5.1 结构体
- 定义：struct 结构体名 { 成员; }
- 成员类型：基本类型、数组、指针（不能是函数）
- 定义方式：定义时直接定义变量、先定义类型后定义变量、无标签结构体
- 初始化：定义时赋值 {1,2}、定义后逐个赋值、字符串成员用 strcpy
- 访问：普通变量用 .，指针用 ->（(*p).成员 等价 p->成员）
- 字节大小：内存对齐，64 位默认对齐值为 8，与成员最大 sizeof 取较小值，按较小值整数倍开辟
- 结构体数组、结构体指针

### 5.2 共用体 union
- 所有成员共用同一块地址，大小为最大成员大小
- 适合节省内存、同一块数据不同解读的场景

### 5.3 枚举 enum
- 枚举成员默认从 0 递增，可手动赋值

### 5.4 typedef 重定义
- typedef 类型 新名；给类型起别名，可简化结构体名

## 六、存储类型与关键字

### 6.1 存储类型
- auto：变量在栈上
- static：变量放静态区；修饰局部变量生命周期延长至整个程序；修饰全局变量 / 函数限制在本文件使用
- extern：声明变量在其他文件
- register：声明变量在寄存器

### 6.2 其他关键字
- const：只读
- volatile：取消编译优化，保证每次都真正读写内存（寄存器、硬件地址必须用）

## 七、动态内存与字符串函数

### 7.1 malloc / free
- void *malloc(size_t size)：开辟堆区空间，成功返回首地址，失败返回 NULL
- void free(void *ptr)：回收堆区空间

### 7.2 string 函数族
- strlen：求长度
- strcpy / strncpy：字符串复制（strncpy 带 n 个字符）
- strcat：字符串拼接
- strcmp：字符串比较（<0 / >0 / ==0）

## 八、预处理与条件编译

### 8.1 宏定义
- #define 宏名 值/表达式/函数：纯文本替换

### 8.2 条件编译
- #ifdef 宏 / #else / #endif：根据宏是否定义
- #if 宏 / #else / #endif：根据宏值是否为真
- #ifndef 宏 / #define 宏 / #endif：防止头文件重复包含

## 九、Linux 系统与常用命令

### 9.1 文件与目录操作
- pwd、ls(-la)、cd(相对 / 绝对路径)、mkdir、rmdir、rm(-r 目录 / -f 强制)、cp(-r 目录)、mv(移动 / 重命名)、touch、cat、less、more、head(-n)、tail(-f)、find、grep

### 9.2 权限管理
- ls -l 解析：文件类型(b c d - l s p)、权限(rwx 三组：自己 / 组内 / 他人)、链接数、所有者、组、大小、时间戳、文件名
- 权限数字：r=4、w=2、x=1，chmod 755
- chown、sudo、whoami、id

### 9.3 通配符
- * 任意长度、? 单个字符、[...] 指定之一、[-] 范围、[^...] 排除、[[:lower:]] / [[:upper:]] 大小写

### 9.4 管道与重定向
- 管道 |：前一个命令输出作为后一个输入
- 输出重定向：> 覆盖、>> 追加、2> 错误、&> 全部
- 输入重定向：<
- 命令置换符：`command`

### 9.5 软件安装
- 软件包：deb(ubuntu) / rpm(redhat)；工具 dpkg(-i/-r/-s/-L)、apt-get(install / remove / purge / update / upgrade / clean)

### 9.6 进程管理
- ps -aux（PID、STAT）、ps -ef（含 PPID）
- 前后台：./a.out &、fg、Ctrl+z、bg、jobs
- top（NI=-20~19 越小优先级越高，PR=NI+20）
- renice 修改优先级
- kill -l 查看信号：2 SIGINT、3 SIGQUIT、9 SIGKILL、15 SIGTERM、20 SIGTSTP

### 9.7 文件系统与压缩
- 目录：/bin /dev /home /mnt /usr /usr/lib /usr/include
- 压缩：zip / unzip、gzip / gunzip、bzip2 / bunzip2
- tar：-c 压缩、-x 解压、-v 显示、-f 指定名、-z(gz)、-j(bz2)（-cjf/-czf 压缩，-xvf 解压）

### 9.8 其他
- 关机 shutdown -h now、重启 shutdown -r now
- 网络：ping、ifconfig
- alias / unalias、history、echo
- 终端快捷键：ctrl+shift+n（当前目录开终端）、ctrl+alt+t（家目录开终端）、ctrl+d（关闭）

## 十、Linux C 开发工具链

### 10.1 gcc 编译四步骤
- 预处理 gcc -E → .i（展开头文件、宏替换、删注释）
- 编译 gcc -S → .s（语法检查、生成汇编）
- 汇编 gcc -c → .o（生成二进制目标文件）
- 链接 gcc .o -o 可执行文件（链接库）

### 10.2 分文件编程
- 一个工程一个 main，多个 .c + 多个 .h
- .h 包含：其他头文件、函数声明、全局变量声明、宏定义、typedef、构造类型
- <> 系统头文件（/usr/include）；"" 自定义头文件（先当前目录后系统）

### 10.3 gdb 调试
- gcc -g 生成调试信息；gdb 进入
- 命令：r 运行、l 查看、b 行号断点、info b、d num、p 变量、s 单步(进函数)、n 单步(不进函数)、c 到下一断点、q 退出

### 10.4 makefile
- 格式：目标:依赖 换行 <Tab>命令
- 目标时间戳比依赖旧才执行命令
- 变量：自定义(= 递归、:= 直接、+= 追加、?= 未定义才赋)、自动($< $^ $@)
- 模式规则 %.o:%.c
- 伪目标 .PHONY:clean 防止同名文件

### 10.5 软链接与硬链接
- 硬链接：ln 源 目标，多个文件名指向同一份数据（相同 inode），删源文件链接仍在，不能链接目录
- 软链接：ln -s 源 目标（快捷方式），inode 不同，可链接目录，删源文件内容消失
