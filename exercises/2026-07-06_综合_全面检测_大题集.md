## 参考答案（做完后看）

### 第1题
`-l` 表示长格式显示（详细信息：权限、链接数、所有者、大小、时间等），`-a` 表示显示所有文件（包括以 `.` 开头的隐藏文件）。
第一列 `-rwxr--r--`：第1个字符 `-` 表示普通文件，后面每3个一组：`rwx` 所有者权限（可读可写可执行）、`r--` 所属组权限（只读）、`r--` 其他人权限（只读）。

### 第2题
四个阶段：**预处理**（展开头文件、替换宏、删除注释）-> **编译**（检查语法，生成汇编）-> **汇编**（生成二进制目标文件 .o）-> **链接**（链接库文件，生成可执行文件）。

### 第3题
按 `i` 进入插入模式（或 `a` / `o` / `I` / `O` / `A`）。
保存退出：先按 ESC 回到命令行模式，输入 `:wq` 回车（写+退出）。
或 `:x` 回车，或 `ZZ`（大写）。

### 第4题
`0x3F` = 二进制 `0011 1111` = 十进制 63（3*16 + 15 = 48 + 15 = 63）。

### 第5题
`'0'` = 48，`'A'` = 65，`'a'` = 97。
`'\0'` = 0（ASCII码0），它是字符串的结束标志，字符串函数遇到 `\0` 就停止处理。

### 第6题
`a / b = 2`（整数除法截断小数部分）；`a % b = 1`（取余数）。
整数除法结果只保留整数部分（向下取整），浮点数除法保留小数。如 `5 / 2 = 2`，但 `5.0 / 2.0 = 2.5`。

### 第7题
逻辑与 `&&` 的截断法则：**左操作数为假（0）时，直接返回假，不再计算右操作数**。
`int a = 0; int b = 1; int c = a++ && b++;` 执行过程：
- `a++` 先取 a 的值 0（假），然后 a 自增为 1
- 因为左操作数为假，`&&` 截断，不执行 `b++`
- 所以 a=1, b=1（没有自增）, c=0

### 第8题
`5 << 2 = 20`（二进制 101 左移2位变成 10100 = 20）。
左移的数学本质：**乘以 2^n**（左移 n 位相当于乘 2 的 n 次方）。
有符号正数左移不会改变符号位，只要不移出有效位导致溢出。

### 第9题
**break**：结束当前（最近一层）循环，跳出循环体。
**continue**：结束本轮循环的剩余语句，直接进入下一轮循环。
在双重循环中，break 只能跳出最近的那一层内层循环，**不能直接跳出外层循环**。要跳出多层循环需要加标志变量或使用 goto。

### 第10题
没有 break 会发生**"穿透"（fall-through）**：从匹配的 case 开始，一直执行到遇到 break 或 switch 结束为止。
例如 `case 1: printf("1"); case 2: printf("2"); break;` 如果输入1，会输出"12"。

### 第11题
- **for 循环**：先判断再执行，适用于已知循环次数的场景
- **while 循环**：先判断再执行，适用于条件控制的场景
- **do-while 循环**：**先执行一次再判断**，至少执行一次循环体
必须用 do-while 的场景：循环体至少需要执行一次的情况，如菜单显示后等待用户选择。

### 第12题
部分初始化时，**未初始化元素自动赋值为 0**。所以 a[3]=0, a[4]=0。
sizeof(a) = 5 * sizeof(int) = 5 * 4 = 20 字节（64位系统 int 占4字节）。

### 第13题
`a` 代表**首行地址**（即第0行的地址），类型是 `int (*)[3]`。
`*(a+1)`：a+1 是第1行地址，加 `*` 解引用后变成第1行第0列的地址（即 `&a[1][0]`）。
`*(*(a+1)+2)` = a[1][2] = 6。

### 第14题
- **sizeof 是关键字**（编译时计算），**strlen 是函数**（运行时计算）
- sizeof 计算的是**数组总字节数**（含 `\0`），strlen 计算的是**字符串实际长度**（不含 `\0`）
- `char arr[] = "Hello";` 数组实际内容为 `"Hello\0"`，所以 sizeof(arr) = 6，strlen(arr) = 5

### 第15题
`**q` = 10（最终指向 a 的值），`*q` = p 的值（即 a 的地址 &a），`q` = &p（p 的地址）。

### 第16题
- `const int *p`：**指向的内容不可修改**，但指针指向可以改（指向别的变量）
- `int * const p`：**指针指向不可修改**，但指向的内容可以改
简洁记忆法：先看 `*` 和 `const` 的位置关系，const 在 `*` 左边修饰内容，const 在 `*` 右边修饰指针本身。

### 第17题
执行 `p++` 后，p 指向 a[1]（即 20）。
**a++ 不可以**！数组名 a 是地址**常量**，不能自增自减。指针 p 是变量，可以修改。

### 第18题
`p` 的类型是 `int (*)[3]`（指向含有3个int的一维数组的指针），即**行指针**。
`p+1` 跳过一整行，即 3 个 int = 3 * 4 = 12 字节。

### 第19题
`arr` 的类型是 `char *[3]`，即**指针数组**（存放 char * 指针的数组，长度为3）。
要打印 "world"：`printf("%s", arr[1]);` 或 `printf("%s", *(arr + 1));`

### 第20题
值传递传递的是**实参的副本**，函数内修改副本不影响实参。
地址传递传递的是**实参的地址**，函数内通过地址间接访问实参，可以修改实参。
要修改主函数中的指针变量本身，需要传**二级指针**（指针的地址）：`void func(int **pp)`。

### 第21题
危险原因：`str[]` 是在栈区分配的局部数组，函数返回后栈空间被回收，返回的地址指向的是已经释放的内存，访问它会产生**野指针**问题（结果不可预知或段错误）。
修改方案：使用 `static` 修饰，或使用堆区 malloc，或让字符串驻留在常量区：
```c
char *getStr() {
    static char str[] = "hello";  // 放在静态区
    return str;
}
// 或
char *getStr() {
    char *p = "hello";  // 常量区，不会释放
    return p;
}
```

### 第22题
```c
int factorial(int n) {
    if (n == 0 || n == 1)  // 终止条件
        return 1;
    return n * factorial(n - 1);
}
```
终止条件：n == 0 或 n == 1 时返回 1，不再递归。
如果没有终止条件，递归会无限进行，最终导致**栈溢出**（Stack Overflow）。

### 第23题
- **strcpy**：字符串复制，将 src 复制到 dest
- **strcat**：字符串拼接，将 src 追加到 dest 末尾
- **strcmp**：字符串比较，比较 s1 和 s2 的 ASCII 码差值
strcmp 返回值是 `>0`、`<0` 或 `==0` 而不是简单的 0/1，是因为它返回的是**两个字符串第一个不同字符的 ASCII 差值**，可以知道 s1 比 s2 大多少或小多少。

### 第24题
忘记 free 会导致**内存泄漏**：堆区空间一直被占用，程序运行越久占用内存越大。
free 之后如果不置为 NULL，指针变成**野指针**，仍然保存着之前释放的地址。如果再使用这个指针访问数据，可能访问到已经被回收的内存，导致不可预知的错误或段错误。

### 第25题
- `.`（点运算符）：用于**结构体变量**访问成员，如 `s.id`
- `->`（箭头运算符）：用于**结构体指针**访问成员，如 `p->id`
`p->id` 和 `(*p).id` **完全等价**。`->` 只是语法糖，让代码更简洁。

### 第26题
结构体字节对齐：为了提高 CPU 访问效率，结构体成员的起始地址必须是其对齐值的整数倍，结构体总大小也必须是对齐值的整数倍。
`struct { char a; int b; char c; }`：
- char a 偏移0，占1字节
- int b 需要4字节对齐，所以从偏移4开始，占4字节（偏移4-7）
- char c 在偏移8，占1字节
- 结构体总大小需对齐到4的倍数，所以填充到12字节
实际占用：**12字节**（如果调整顺序为 int/char/char 则只需要8字节）。

### 第27题
核心区别：**结构体的所有成员各自独立占用内存空间**，**共用体的所有成员共享同一块内存空间**。
修改共用体一个成员会影响其他成员，因为它们共用同一块内存地址，修改一个等于修改了所有。

### 第28题
MON=1, TUE=2（MON+1）, WED=5, THU=6（WED+1）, FRI=7（THU+1）
枚举值默认从0开始，但可以手动指定值，后面的值在前一个基础上+1。

### 第29题
- **typedef 是类型重定义**，由编译器处理，创建新的类型名
- **#define 是宏替换**，由预处理器处理，简单的文本替换
不同效果：
```c
typedef int *ptr;
ptr a, b;  // a是int*, b是int*

#define ptr int *
ptr a, b;  // 预编译后变成：int * a, b; 所以a是int*, b是int
```

### 第30题
static 修饰局部变量时：**延长生命周期至整个程序**，且**只初始化一次**，函数多次调用时变量的值会保持。
```c
void countCall() {
    static int cnt = 0;
    cnt++;
    printf("第%d次被调用\n", cnt);
}
```
第一次调用输出"第1次被调用"，第二次输出"第2次被调用"...

### 第31题
`#ifdef`：如果定义了某个宏则编译相应代码（调试开关等）
`#ifndef`：如果没有定义某个宏则编译相应代码
头文件中的 `#ifndef __HEADER_H__ ... #define __HEADER_H__ ... #endif` 叫做**头文件保护**（Include Guard），防止头文件被重复包含，避免重复定义错误。

### 第32题
- `"r"`：只读模式，文件必须存在，不存在则返回 NULL
- `"w"`：只写模式，**文件不存在则创建**，**存在则清空内容**
- `"a"`：追加模式，文件不存在则创建，写入内容追加到文件末尾

### 第33题
fread 的四个参数：`fread(缓冲区地址, 每个元素字节数, 元素个数, 文件指针)`
fwrite 的四个参数：`fwrite(缓冲区地址, 每个元素字节数, 元素个数, 文件指针)`
用 fwrite 写 int 数组时写的是**二进制数据**。
优点：占空间小、读写速度快、保留数据原始精度。
缺点：生成的文件不是人类可读的文本，不同平台间可能有字节序问题（大小端）。

### 第34题
last 代表**最后一个有效元素的下标**。
初始化为 -1 的原因：空顺序表中没有有效元素，下标从 0 开始，所以 last = -1 表示"没有任何有效元素"。如果初始化为 0，会误以为 a[0] 位置已经有一个有效元素。

### 第35题
**必须从最后一个元素开始向后移动**。如果从插入位置开始向前移动，前面的元素会覆盖后面的元素，导致数据丢失。
从后往前移动：每个元素先移动到后面空位，保证互不覆盖。
时间复杂度：**O(n)**（最坏情况下需要移动所有元素）。

### 第36题
- **有头链表**：存在一个头节点，数据域无效（通常不放数据），指针域指向第一个有效节点
- **无头链表**：所有节点的数据域和指针域都有效，第一个节点就是有效数据节点
头节点的数据域一般不存放有效数据，也可以用来存放链表长度等信息。

### 第37题
核心思路：**将原链表的每个节点依次取下来，用头插法插入到头节点后面**。
原本第一个节点会被头插到新链表的最末尾，原最后一个节点会被头插到第一个，从而实现逆序。
第一步将头节点 next 置为 NULL，相当于创建一个空链表，然后逐个头插。

### 第38题
单向链表删除已知节点 p 时，需要知道 **p 的前驱节点**（prev），因为要修改 prev->next 跳过 p。
双向链表不需要这个信息，因为双向链表的节点有 prev 指针，通过 `p->prev` 可以直接找到前驱节点。
所以：单向链表删除已知节点的时间复杂度是 O(n)（需要遍历找前驱），双向链表是 O(1)。

### 第39题
算法过程：
1. 遍历字符串的每个字符
2. 遇到左括号 `(`、`[`、`{`，将其入栈
3. 遇到右括号 `)`、`]`、`}`，先检查栈是否为空。为空 → 缺少左括号，不匹配；不为空 → 出栈栈顶元素，对比类型是否一致
4. 遍历结束后检查栈是否为空。为空 → 所有括号匹配；不为空 → 有左括号未被匹配
对于 `{[()]}`：匹配成功。对于 `({[)]}`：遇到 `)` 时栈顶是 `[`，类型不匹配 → 失败。

### 第40题
- **顺序栈**（基于数组）：优点——访问速度快、空间利用率高；缺点——容量固定、可能溢出
- **链式栈**（基于链表）：优点——容量动态扩展、不会溢出；缺点——每个节点多一个指针域，空间开销大
顺序栈适用于**已知最大容量**的场景，链式栈适用于**不确定容量**的场景。

### 第41题
循环队列为了解决"假溢出"问题：数组前面还有空位，但 rear 指针已经到数组末尾无法继续入队。
队头指针 front 指向队首，队尾指针 rear 指向队尾的下一个位置。
移动规则：`front = (front + 1) % MAX_SIZE`，`rear = (rear + 1) % MAX_SIZE`
判断空满：
- 空：`front == rear`
- 满：`(rear + 1) % MAX_SIZE == front`（牺牲一个元素空间来区分空满）

### 第42题
- **先序遍历**：根 -> 左 -> 右（根在第一个）
- **中序遍历**：左 -> 根 -> 右（根在中间）
- **后序遍历**：左 -> 右 -> 根（根在最后一个）
3个节点（根-左-右）：
- 先序：根, 左, 右
- 中序：左, 根, 右
- 后序：左, 右, 根

### 第43题
```c
int depth(bitree_p root) {
    if (root == NULL)         // 空树深度为0
        return 0;
    int leftDepth = depth(root->lchild);
    int rightDepth = depth(root->rchild);
    return (leftDepth > rightDepth ? leftDepth : rightDepth) + 1;
}
```
递归终止条件：`root == NULL` 时返回 0。

### 第44题
**叶子节点**：没有子节点的节点（左右孩子都为 NULL）。
```c
int leafCount(bitree_p root) {
    if (root == NULL)
        return 0;
    if (root->lchild == NULL && root->rchild == NULL)
        return 1;                        // 叶子节点
    return leafCount(root->lchild) + leafCount(root->rchild);
}
```
如果二叉树只有一个根节点（左右孩子都为空），该节点也是叶子节点，返回 **1**。

### 第45题
大 O 表示法描述**算法的时间复杂度**，即随着问题规模 n 增大，算法执行时间的增长趋势。
四条规则：
1. 如果有常数项，将其置为 1（如 f(n)=8 → O(1)）
2. 只保留最高项，其他项舍去
3. 如果最高项系数不为 1，除以最高项系数
4. 最终用 O(f(n)) 表示
示例：`f(n) = 3n^4 + 2n^3 + 6n^2 + 10` → O(n^4)

### 第46题
双重等量循环 `for(i=0; i<n; i++) for(j=0; j<n; j++)`：内层 n 次，外层 n 次 → **O(n^2)**
如果把内层改为 `j < i`：外层 i 从 0 到 n-1，内层次数为 0+1+2+...+(n-1) = n(n-1)/2 → **O(n^2)**
虽然系数不同，但大 O 表示法下都是 O(n^2)。增长率相同，常数被省略。
