## 一、STM32 基础

### 1. 计算机基础
- 计算机组成：输入设备、输出设备、运算器（ALU）、控制器、存储器（ROM/RAM）
- 存储器分类：
  - ROM（Read Only Memory）：掉电不丢失（硬盘、Flash/EMMC），作程序存储器
  - RAM（Random Memory）：内存，掉电丢失，存临时数据
- 三级存储结构：寄存器 > 缓存 > 主存 > 外存（速度由快至慢）
- 总线分类：
  - 数据总线：宽度决定 CPU 与外界数据传输速度
  - 地址总线：宽度决定 CPU 的寻址能力（最大内存空间）
  - 控制总线：宽度决定 CPU 对外部器件的控制能力

### 3. ARM 架构与指令集
- ARM 是三合一：一家公司（IP 授权）、一款处理器内核、一款指令集
- 指令集分类：
  - 精简指令集(RISC)-->微处理器
优点：功耗低，便宜，体积小，指令简短，散热需求小
缺点：指令集相对复杂指令集性能更差
ARM 属于 RISC
  - 复杂指令集(CISC)-->电脑CPU
优点：运算速度更快
缺点：功耗高，成本高，指令集复杂，散热需求高


### 4. Cortex-M33
- 定位：中高端嵌入式处理器，面向 IoT、实时控制、安全关键应用
- 采用 ARMv8 架构，32 位 AHB 总线，支持多主设备并发访问
- 组成：处理器内核、NVIC、调试子系统、内部总线
- 工作模式：
  - 线程模式：复位后执行用户程序
  - 处理模式：发生异常/中断时执行，处理完返回线程模式

### 5. 开发环境
- STM32CubeMX：工程项目搭建与配置、选型、图形化引脚配置（含冲突提示）、时钟树配置、参数初始化
- Keil5（MDK）：μVision5（IDE，含编辑器/编译器/调试器）、ARM 编译器、Device Family Pack、Debugger

### 6. 基本电路知识
- 二极管：正向导通、反向截止；导通压降约 0.7V；发光二极管即 LED
- 三极管：相当于开关
  - NPN：基极高于发射极时导通，高电平导通，电流从集电极流向发射极
  - PNP：基极低于发射极时导通，低电平导通，电流从发射极流向集电极
- 上拉电阻：VCC 经电阻接信号线，无信号时保持高电平
- 下拉电阻：GND 经电阻接信号线，无信号时保持低电平

## 二、GPIO

### 1. 概念
- GPIO（General Purpose Input/Output）：通用输入输出接口
- 输入：采集信息/电压（传感器、按键）
- 输出：控制外部设备（LED、马达、蜂鸣器、继电器、风扇）
- VDD：器件内部工作电压；VCC：接入电路电压；VSS：公共接地端

### 2. 施密特触发器（TTL）
- 作用：去除噪声、波形整形（把缓变沿变成陡峭方波）、提高抗干扰能力
- 原理：滞回效应，存在两个触发电平（上触发 VT+、下触发 VT-），可消除抖动

### 3. 输入模式
- 浮空输入：上下拉均不接，电平完全由外界决定；用于开关状态读取、标准通信协议（如 USART）
- 上拉输入：无信号时默认高电平；用于输入信号不稳定的场合
- 下拉输入：无信号时默认低电平
- 模拟输入：原汁原味信号，不经上下拉、关闭施密特触发器，直接送片上外设；用于 ADC 采集

### 4. 输出模式
- 推挽输出：P-MOS + N-MOS 配合，既能输出高电平又能输出低电平（最常用）
  - 输出数据寄存器 = 0 → N-MOS 导通 → 输出低电平
  - 输出数据寄存器 = 1 → P-MOS 导通 → 输出高电平
- 开漏输出：只用 N-MOS，只能输出低电平或高阻态；需外接上拉电阻才能输出高电平，上拉电压可自定，便于电平匹配
- 复用推挽 / 复用开漏：供外设复用功能（如串口、SPI 引脚）使用

### 5. 寄存器配置（点灯核心流程）
配置某引脚（如 PC13）输出高电平的 6 步：
1. 打开时钟使能寄存器 RCC_AHB2ENR（对应位写 1）
2. 配置端口模式寄存器 GPIOx_MODER（输出模式）
3. 配置端口输出类型寄存器 GPIOx_OTYPER（推挽/开漏）
4. 配置端口输出速度寄存器 GPIOx_OSPEEDR
5. 配置上下拉寄存器 GPIOx_PUPDR
6. 配置输出数据寄存器 GPIOx_ODR（写高/低电平）

- 置 0 公式：`寄存器 &= ~(1 << n)`
- 置 1 公式：`寄存器 |= (1 << n)`

### 6. HAL 库常用函数
- `HAL_GPIO_WritePin(端口, 引脚, 电平)`：写电平（GPIO_PIN_SET=1 / GPIO_PIN_RESET=0）
- `HAL_GPIO_ReadPin(端口, 引脚)`：读电平，返回引脚状态
- `HAL_GPIO_TogglePin(端口, 引脚)`：翻转电平
- `HAL_Delay(毫秒)`：延时

## 三、USART 串口

### 1. 通信基本概念
- 串口：将 CPU 的并行数据转换为串行数据流发送，或反之
- 通信要素：至少两个端（发送端、接收端）、信息传递、数据交互
- 信号类型：
  - 电平信号：单根信号线电压高低表示逻辑（高=1，低=0）
  - 差分信号：两根信号线电压差的正负表示逻辑

### 2. 通信划分
- 按传输方式：
  - 串行通信：同一时刻传 1 bit，一根线；节省引脚、速度慢
  - 并行通信：同一时刻传多位，多根线；速度快、占用引脚多
- 按传输方向：
  - 单工：只能收或只能发（广播）
  - 半双工：可收可发但不能同时（对讲机）
  - 全双工：可同时收发（手机）
- 按时钟信号：
  - 同步通信：双方共享时钟（SPI 全双工、I2C 半双工），发送时阻塞等待
  - 异步通信：各自独立时钟、约定速率（UART），发送无阻塞
- 波特率：每秒发送的位数（bps），常见 9600bps、115200bps

### 3. USART 与 UART
- USART：支持同步或异步通信，全双工，串行
- UART：无时钟线，只支持异步通信，全双工，串行
- 关系：USART 放弃时钟线即为 UART（包含关系）
- 发送过程：CPU/DMA 写 TDR → 硬件检测移位寄存器 → 空闲则放入；TDR 空时 TXE 置 1
- 接收过程：RX 口读电平 → 逐位移入接收移位寄存器 → 满 8 位放入 RDR → RDR 非空 RXNE 置 1

### 4. 数据帧格式
1. 空闲状态：信号线保持高电平（抗干扰强）
2. 起始位：1 bit，低电平
3. 数据位：7/8/9 位可选
4. 校验位（可配置）：奇校验/偶校验，只能发现错误不能纠正
5. 停止位：拉回高电平

### 5. 逻辑电平标准
- TTL：逻辑 1 = 2.4V~5V，逻辑 0 = 0~0.5V
- RS-232：+3V~+15V 为逻辑 0，-3V~-15V 为逻辑 1；抗干扰更强
- RS-485：差分信号、二线制、半双工、电气协议；速率可达 10Mbit/s，理论距离 1200 米

### 6. 相关寄存器
- USART_CR：控制寄存器（帧格式、功能初始化）
- USART_BRR：波特率寄存器
- USART_TDR：发送数据寄存器
- USART_RDR：接收数据寄存器
- USART_ISR：中断和状态寄存器（TXE、RXNE 等标志）

## 四、SPI

### 1. 概念
- SPI：Motorola 提出的全双工三/四线同步串行外围接口，主从（Master/Slave）架构
- 高位在前（MSB first），时钟由主机控制
- 用于 FLASH、ADC、LCD 等高速通信场合

### 2. 四根线
1. SCLK：时钟线（主机产生）
2. MOSI：主机输出、从机输入
3. MISO：主机输入、从机输出
4. NSS：片选线，低电平有效
- 三线场景（引脚受限）：单工只留一根单向数据线，半双工只留一根双向数据线

### 3. 时序与字节交换
- 起始条件：NSS 由高→低；结束条件：NSS 由低→高
- 字节交换基于"位"：移出（最高位写信号线后整体左移一位）+ 移入/采样（读信号线电平放最低位），主机从机同时进行

### 4. 工作模式（CPOL + CPHA）
- CPOL（时钟极性）：决定空闲时时钟电平（0 低 / 1 高）
- CPHA（时钟相位）：决定在哪个边沿采样
- 四种组合：
  - CPOL=0, CPHA=0：空闲低，上升沿采样
  - CPOL=0, CPHA=1：空闲低，下降沿采样
  - CPOL=1, CPHA=0：空闲高，下降沿采样
  - CPOL=1, CPHA=1：空闲高，上升沿采样
- 主机按从机支持的模式配置，主从需一致

### 5. 数码管
- 由 8 个 LED（7 段 + 小数点）封装；分共阴极（高电平点亮）与共阳极（低电平点亮）
- 74HC595：移位寄存器，串行转并行，一脚控多脚，可级联

### 6. LCD（ILI9341）
- ILI9341：240RGB×320 点阵 a-TFT LCD 驱动器，支持 8/9/16/18 位并行总线、RGB 接口、3/4 线 SPI

## 五、IIC

### 1. 概念
- IIC（I2C，Inter-Integrated Circuit）：飞利浦发明的多主从串行总线，半双工、同步传输
- 两线：SCL（时钟线）、SDA（数据线）
- 总线上每个设备有唯一地址

### 2. 上拉电阻的作用
1. 空闲时保持两线高电平
2. IIC 用开漏输出，自身无法输出高电平，需外部上拉
3. 高/低电平由内部 N-MOS 管通断决定（导通拉低，关断高阻、上拉拉高）
4. 实现"线与"逻辑与总线仲裁（一低则低，发 1 读回 0 则主动退出竞争）
5. 兼容不同电压设备（上拉电源决定总线高电平）
6. 简化设备设计（只需 NMOS 下拉开关）

### 3. 特性
- 主设备产生时钟、起始/停止信号；从设备做地址检测
- 支持多主控（任一时刻只有一个主控）
- 速率：标准 100kHz、快速 400kHz
- SCL/SDA 都需上拉电阻（一般 3.3K~10K）
- 半双工，先发从机地址再发命令/数据，支持多字节连续读写
- 各设备输出端必须是开漏 N-MOS

### 4. 时序
- 起始信号：SCL 高电平期间，SDA 由高→低（主机发出，总线被占用）
- 停止信号：SCL 高电平期间，SDA 由低→高（主机发出，总线空闲）
- 数据传输：SCL 高电平期间数据必须稳定（接收器读取）；SCL 低电平期间数据允许变化（发送器写入）
- 每个字节 8 位，高位先传，字节后跟 1 个应答位（第 9 个时钟）
- 应答：第 9 个时钟接收器写、发送器读；低电平 = 应答 ACK，高电平 = 非应答 NACK

## 六、中断（NVIC / EXTI）

### 1. 中断基本概念
- 中断：对突发事件的处理过程——暂停当前程序，处理紧急事件，处理完返回继续
- 意义：实现程序并行化（时间片），提高 CPU 效率，保证实时性
- 处理过程：
  1. 主程序正在运行
  2. 中断发生，处理器自动保存程序状态与参数到堆栈（保护现场）
  3. 根据中断向量跳转到中断服务程序
  4. 执行完中断服务程序，恢复现场，返回继续执行主程序

### 2. 中断 vs 异常
- 异常：通常由处理器内部导致（多为软件错误）
- 中断：由外部事件引起，通过中断通道送入处理器（多为硬件引起）

### 3. NVIC（嵌套向量中断控制器）
- 与内核捆绑，实现低延迟中断处理
- 主要功能：
  1. 管理中断事件（优先级低的挂起、执行完清除）
  2. 支持中断和异常的向量化处理（中断向量表：异常/中断服务程序入口地址按优先级排布）
  3. 支持中断嵌套
- 中断优先级：由 4 位优先级寄存器（0~15）决定，切分为抢占优先级（高 n 位）+ 响应优先级（低 4-n 位）
  - 抢占优先级：决定能否打断正在执行的中断服务程序（高的可嵌套抢占）
  - 响应优先级：抢占优先级相同时生效（同时到达时高的优先处理）
  - 抢占/响应都相同时按中断向量号排队
  - 数值越小优先级越高，复位优先级最高

### 4. EXTI（外部中断/事件控制器）
- 位于 CPU 外部，对中断和事件进行初步筛选
- 中断：能打断 CPU，送入 NVIC 运行中断服务程序
- 事件：送给外设的脉冲信号，硬件级（电路级）传输
- 处理流程：信号输入口（最多 26 个）→ 边沿检测电路（上升沿/下降沿）→ 或门 → 与门（事件/中断屏蔽寄存器）→ 挂起请求寄存器 → NVIC

## 七、ADC + DMA

### 1. ADC 基础
- 模拟信号（A）：连续变化的物理量（温度、湿度、压力、电压等）
- 数字信号（D）：离散的二进制数
- 转换器（C）：将一种信号转换为另一种信号
- ADC（模数转换器）：将连续模拟信号转为离散数字信号，需参考电压作为转换标准

### 2. 逐次逼近型 ADC
- 原理：二分法逐位逼近（从 MSB 开始猜，比较大小决定保留 1 还是 0）
- 例：4 位、参考 5V、输入 3.2V → 结果 1010
- 优点：低功耗、精度准确；缺点：计算速度慢

### 3. ADC 特性
- 量程：0~3.3V（VSS~VDD，供电 2.0~3.6V）
- 分辨率：输出二进制位数，位数越多分辨率越高（6/8/10/12 位），分辨率越高转换时间越长
- 转换时间：从转换开始到获得稳定数字量所需时间

### 4. 工作模式
- EOC：通道转换结束标志；EOS：序列转换结束标志
- 连续/非连续由 COUNT 位标识（COUNT=1 连续，COUNT=0 非连续）
- 模式：单通道单次、单通道连续、多通道扫描单次、多通道扫描连续、间隔转换

### 5. DMA（直接内存访问）
- 概念：硬件设备直接访问内存，不经 CPU 介入，用于高速数据搬运
- 作用：外设与内存间直接传数据，节省 CPU 资源、提高 CPU 效率
- 特性：
  - 多优先级请求（很高/高/中/低）
  - 每通道 3 个事件标志：半传输、传输完成、传输出错
  - 数据宽度：字节(8)/半字(16)/全字(32)
  - 传输方向：外设→内存、内存→外设、内存→内存
  - GPDMA 有 16 个通道
- 寄存器：DMA_CPARx（外设地址）、DMA_CMARx（存储器地址）、DMA_CCRx（传输方向）、DMA_CNDTRx（数据量）
- 模式：
  - 增量模式：每次传输后地址递增
  - 循环模式：传输完成后回到起始地址重复搬移

## 八、PCB 基本元器件与要点

### 1. 电阻
- 原理：基于欧姆定律，阻值取决于材料、长度、横截面积
- 作用：限制电流、调节电压与电流、保护电路
- 分类：贴片电阻等

### 2. 电容
- 单位：法拉（F），常用毫法 mF、微法 μF、纳法 nF、皮法 pF
- 特性：电压不突变，阻碍电压变化，通交隔直，可用于滤波

### 3. 其他要点
- 晶振：时钟系统必用（提供时钟基准）；烧录、供电、复位是电路的基础
- 三极管 vs MOS 管：都可用作开关，三极管为电流驱动，MOS 管为电压驱动
- 负载：电路需要负载的原因（吸收能量、匹配、稳定等）
- LDO vs DC-DC：
  - LDO（低压差线性稳压器）：纹波小、电路简单，但效率较低（压差大时发热）
  - DC-DC（开关电源）：效率高、可升压降压，但纹波较大、电路较复杂

> 说明：PCB 部分原始笔记较简略，"三极管 vs MOS、负载、LDO vs DC-DC"在笔记中仅列出标题，上述要点为通用补充，具体考点建议结合课堂内容确认。

## 九、WIFI（ESP8266 / AT 指令）

### 1. 概念
- ESP8266：安信可 WIFI 模组，UART-WiFi（串口转 WIFI）
- 有线 vs 无线：PC—U5 用线（有线）；PC—ESP8266—U5 中，PC—ESP8266 为无线，ESP8266—U5 为串口
- 固件：用户不能修改、靠发送指令控制的代码，可烧写更新

### 2. 工作模式（GPIO0）
- GPIO0 低电平：下载模式（下载固件）
- GPIO0 高电平：运行模式（通信）

### 3. AT 指令（每条以 \r\n 结尾）
- `AT`：检测
- `AT+RST`：复位
- `AT+CWMODE=`：设置 WIFI 模式
  - 0：无 WiFi 模式
  - 1：Station 模式（连接其他热点）
  - 2：SoftAP 模式（自身成为热点，只能发射不能联网）
  - 3：SoftAP+Station 混合模式
- `AT+CWJAP="热点名称","热点密码"`：连接热点
- `AT+CIPSTART="TCP","IP地址",端口号`：连接 TCP 服务器
  - 错误码：1 连接超时、2 密码错误、3 找不到 AP、4 连接失败
- `AT+CIPSEND=数量`：发送指定数量字符
- 透传模式：
  - `AT+CIPMODE=1`（开启）/ `AT+CIPMODE=0`（取消）
  - `AT+CIPSEND` 进入透传
  - 退出透传：单独数据包 `+++`

## 十、FreeRTOS

### 1. RTOS 概念
- RTOS（实时操作系统）：按排序运行、管理系统资源，最大特色是"实时性"——任务需要执行时能在较短时间内执行，无较长延时

### 2. 裸机开发 vs RTOS
- 任务模型：裸机单线程（main 循环 + 中断）；RTOS 多任务（调度器统一管理）
- 任务调度：裸机无调度器（轮询 + 中断打断）；RTOS 按优先级/时间片抢占调度
- 并发能力：裸机一次一件事；RTOS 多任务"并发"（宏观并行、微观快速切换）
- 上下文切换：裸机基本无（仅中断保护现场）；RTOS 有（保存/恢复现场，带来开销）
- 实时性：裸机由开发者保证；RTOS 调度器保证高优先级及时响应
- 资源管理：裸机手工（全局变量/静态）；RTOS 提供队列、信号量、互斥锁
- 中断处理：裸机 ISR 里直接干活；RTOS ISR 尽量短，用信号量/队列通知任务
- 内存管理：裸机静态分配为主；RTOS 常带动态内存（heap），需防碎片
- 适用场景：裸机功能简单、资源紧张；RTOS 功能复杂、多任务、需实时响应
- 一句话：裸机"一个人从头忙到尾"，RTOS"请了管家（调度器）排班分工"

### 3. 多任务
- 任务：RTOS 基本组成单元，是 Linux 进程 + 线程的结合体
- 任务间可通过全局变量通信，每个任务有独立栈空间
- 多任务访问同一资源会产生临界资源问题，用互斥锁、信号量（PV 操作）解决；也可用队列通信
- 优先级：高优先级先执行，同优先级抢时间片，中断最先执行

### 4. 调度原理
- 调度器职责：决定"现在轮到哪个任务跑 CPU"
- 抢占式调度（不同优先级）：高优先级就绪立刻抢占 CPU，只有高优先级阻塞/挂起时低优先级才运行
- 时间片调度（同优先级）：轮流运行，每个任务跑 1 个时间片（1ms）
- 滴答（系统节拍）：硬件定时器按固定频率产生中断，是时间基准；频率由宏 `configTICK_RATE_HZ` 决定，一般 1000Hz（1ms 一次）；本质是 Cortex-M 内核的 SysTick

### 5. 任务四种状态
- 运行态：任务获得 CPU 使用权被实际执行（单核任意时刻仅一个）
- 就绪态：已能执行但当前未被执行
- 阻塞态：因延时或等待外部事件（vTaskDelay、等队列/信号量等），有超时时间，超时解除
- 挂起态：vTaskSuspend 进入、vTaskResume 退出，不能被运行

### 6. 任务操作
- 创建任务 `osThreadNew(func, argument, attr)`：返回句柄；参数为任务函数、参数（不传填 NULL）、属性（名字/优先级/栈大小）
- 挂起 `vTaskSuspend(句柄)`（NULL 挂起自身）；恢复 `vTaskResume(句柄)`
- 删除 `osThreadTerminate(句柄)`

### 7. 空闲任务
- 调度器启动（vTaskStartScheduler）时自动创建，优先级最低（0）
- 作用：无其他任务运行时维持系统运作、资源维护（清理内存）、节能调度（触发休眠）、通过空闲钩子函数扩展
- 调度器代码位于主函数 `osKernelStart`

















# 第二部分：参考答案

## 一、STM32 基础

**Q1.** 输入设备（其他信号转电信号）、输出设备（电信号转其他信号）、运算器（CPU 算术/逻辑运算）、控制器（指挥中心）、存储器（存程序和数据）。

**Q2.** ROM 掉电不丢失（硬盘/Flash/EMMC，程序存储器）；RAM 掉电丢失（内存，存临时数据）。

**Q3.** 数据总线决定 CPU 数据传输速度；地址总线决定 CPU 寻址能力（最大内存空间）；控制总线决定对外部器件的控制能力。

**Q4.** 将 CPU、RAM、ROM、定时器、I/O 口、中断系统集成到一块硅片上的微型计算机系统。

**Q5.** 51（8 位）：AT89C51、STC89C51；32（32 位）：STM32、GD32。处理器位数 = CPU 单次运算最大的处理数据位数。

**Q6.** ALU 处理数据宽度不同，32 位单次处理数据更多、性能更强。

**Q7.** 算术逻辑单元，含算术单元 + 逻辑单元，由大量晶体管构成，通过操作码（如加法 0010）执行运算。

**Q8.** 一家公司（IP 授权）、一款处理器内核、一款指令集。Cortex-A（高性能应用）、Cortex-R（实时）、Cortex-M（微控制器）。

**Q9.** RISC 精简指令集，只留常用指令，硬件简单、指令定长多单周期，功耗低、便宜、体积小，但性能较弱。CISC 复杂指令集，含特殊指令，硬件复杂、长度周期不固定，速度快但功耗高、成本高、散热大。ARM 属于 RISC。

**Q10.** 中高端嵌入式处理器，面向 IoT/实时控制/安全关键，ARMv8 架构、32 位 AHB 总线。线程模式（复位后执行用户程序）、处理模式（异常/中断时执行，处理完返回线程模式）。

**Q11.** 二极管正向导通、反向截止，压降约 0.7V。三极管作开关：NPN 基极高于发射极导通（高电平导通，电流集电极→发射极）；PNP 基极低于发射极导通（低电平导通，电流发射极→集电极）。

**Q12.** 上拉：VCC 经电阻接信号线，无信号时保持高电平；下拉：GND 经电阻接信号线，无信号时保持低电平。

## 二、GPIO

**Q1.** General Purpose Input/Output，通用输入输出接口。输入采集信息（传感器、按键），输出控制设备（LED、马达、蜂鸣器等）。

**Q2.** 去除噪声、波形整形（缓变沿变陡峭方波）、提高抗干扰能力；靠滞回效应（VT+、VT- 两个触发电平）消除抖动。

**Q3.** 浮空输入（上下拉都不接，电平由外界定，用于开关读取/USART）；上拉输入（无信号默认高电平，用于信号不稳定）；下拉输入（无信号默认低电平）；模拟输入（原汁原味，不经上下拉、关施密特触发器，用于 ADC 采集）。

**Q4.** 推挽用 P-MOS+N-MOS，既能输出高电平也能输出低电平（最常用）；开漏只用 N-MOS，只能输出低电平或高阻态，需外接上拉才能输出高电平，上拉电压可自定便于电平匹配。

**Q5.** 1 开时钟使能 RCC_AHB2ENR → 2 模式寄存器 GPIOx_MODER（输出）→ 3 输出类型 OTYPER（推挽/开漏）→ 4 输出速度 OSPEEDR → 5 上下拉 PUPDR → 6 输出数据 ODR（写电平）。

**Q6.** 置 0：`寄存器 &= ~(1 << n)`；置 1：`寄存器 |= (1 << n)`。

**Q7.** `HAL_GPIO_WritePin(端口,引脚,电平)` 写电平；`HAL_GPIO_ReadPin(端口,引脚)` 读电平；`HAL_GPIO_TogglePin(端口,引脚)` 翻转电平；`HAL_Delay(毫秒)` 延时。

## 三、USART 串口

**Q1.** 将 CPU 并行数据转串行数据流发送，或反之。三要素：至少两个端（发送端、接收端）、信息传递、数据交互。

**Q2.** 电平信号用单线电压高低表示逻辑（高=1，低=0）；差分信号用两线电压差的正负表示逻辑。

**Q3.** 串行同一时刻传 1 bit、一根线，省引脚、速度慢；并行同一时刻传多位、多根线，速度快、占引脚多。单工只能收或发（广播）；半双工可收发但不能同时（对讲机）；全双工可同时收发（手机）。同步双方共享时钟（SPI/I2C），发送阻塞；异步各自时钟、约定速率（UART），发送无阻塞。

**Q4.** 每秒发送的位数（bps）。常见 9600bps、115200bps。

**Q5.** USART 支持同步或异步、全双工、串行；UART 无时钟线、只支持异步、全双工、串行。USART 放弃时钟线即为 UART（包含关系）。

**Q6.** 空闲状态（高电平）→ 起始位（1 bit 低电平）→ 数据位（7/8/9 位）→ 校验位（可配置，奇/偶校验，只能发现不能纠正）→ 停止位（拉回高电平）。

**Q7.** TTL：1=2.4~5V，0=0~0.5V。RS-232：+3~+15V 为 0，-3~-15V 为 1，抗干扰更强。RS-485：差分信号、二线制、半双工，速率可达 10Mbit/s，理论距离 1200 米。

**Q8.** USART_CR（控制/帧格式）、USART_BRR（波特率）、USART_TDR（发送数据）、USART_RDR（接收数据）、USART_ISR（中断和状态，TXE/RXNE 等）。

## 四、SPI

**Q1.** Motorola 提出的全双工三/四线同步串行外围接口，主从架构，高位在前，时钟由主机控制。四线：SCLK（时钟）、MOSI（主机出从机入）、MISO（主机入从机出）、NSS（片选，低电平有效）。

**Q2.** 起始：NSS 由高→低；结束：NSS 由低→高。

**Q3.** 基于"位"交换：移出（最高位写信号线后整体左移一位）+ 移入/采样（读信号线电平放最低位），主机从机同时进行。

**Q4.** CPOL 时钟极性（决定空闲电平），CPHA 时钟相位（决定采样边沿）。CPOL=0/CPHA=0 空闲低、上升沿采样；CPOL=0/CPHA=1 空闲低、下降沿采样；CPOL=1/CPHA=0 空闲高、下降沿采样；CPOL=1/CPHA=1 空闲高、上升沿采样。主从需一致。

**Q5.** 共阴极高电平点亮，共阳极低电平点亮。74HC595 是移位寄存器，串行转并行，一脚控多脚，可级联。

## 五、IIC

**Q1.** 飞利浦发明的多主从串行总线，半双工、同步传输。两线：SCL（时钟）、SDA（数据），总线上每个设备有唯一地址。

**Q2.** 1 空闲保持两线高电平；2 开漏输出自身无法输出高电平需外部上拉；3 高低电平由内部 N-MOS 通断决定；4 实现线与逻辑与总线仲裁；5 兼容不同电压设备；6 简化设备设计（只需 NMOS 下拉开关）。

**Q3.** 起始：SCL 高电平期间，SDA 由高→低（总线被占用）；停止：SCL 高电平期间，SDA 由低→高（总线空闲）。均由主机发出。

**Q4.** SCL 高电平期间数据必须稳定（接收器读取）；SCL 低电平期间数据允许变化（发送器写入）。

**Q5.** 每个字节 8 位、高位先传，字节后跟 1 个应答位（第 9 个时钟）。第 9 个时钟接收器写、发送器读；低电平 = 应答 ACK，高电平 = 非应答 NACK。

## 六、中断（NVIC / EXTI）

**Q1.** 中断是对突发事件的处理——暂停当前程序，处理紧急事件，处理完返回继续。意义是实现程序并行化（时间片）、提高 CPU 效率、保证实时性。过程：主程序运行 → 中断发生自动保存现场到堆栈 → 按中断向量跳转到中断服务程序 → 执行完恢复现场返回主程序。

**Q2.** 异常通常由处理器内部导致（多为软件错误）；中断由外部事件引起，通过中断通道送入处理器（多为硬件引起）。

**Q3.** 1 管理中断事件（挂起/清除）；2 支持中断和异常的向量化处理（中断向量表）；3 支持中断嵌套。

**Q4.** 抢占优先级决定能否打断正在执行的中断服务程序（高的可嵌套抢占）；响应优先级在抢占优先级相同时生效（同时到达时高的优先处理）；都相同时按中断向量号排队。数值越小优先级越高，复位优先级最高。

**Q5.** 由 4 位优先级寄存器（0~15）决定，切分为高 n 位抢占优先级 + 低 4-n 位响应优先级。

**Q6.** EXTI 在 CPU 外部对中断和事件初步筛选。中断能打断 CPU，送入 NVIC 运行中断服务程序；事件是送给外设的脉冲信号，硬件级（电路级）传输。

**Q7.** 信号输入口（最多 26 个）→ 边沿检测电路（上升沿/下降沿）→ 或门 → 与门（事件/中断屏蔽寄存器）→ 挂起请求寄存器 → NVIC。

## 七、ADC + DMA

**Q1.** ADC（模数转换器）将连续模拟信号转为离散数字信号，需参考电压作标准。模拟信号连续变化（温度、湿度、电压等）；数字信号是离散的二进制数。

**Q2.** 二分法逐位逼近（从 MSB 开始猜，比较大小决定保留 1 或 0）。例：4 位、参考 5V、输入 3.2V → 1010。优点：低功耗、精度准；缺点：速度慢。

**Q3.** 量程 0~3.3V（VSS~VDD）；分辨率是输出二进制位数（6/8/10/12 位），位数越多分辨率越高、转换时间越长；转换时间是从开始到获得稳定数字量所需时间。

**Q4.** EOC 是通道转换结束标志，EOS 是序列转换结束标志。连续/非连续由 COUNT 位决定（1 连续、0 非连续）。模式：单通道单次、单通道连续、多通道扫描单次、多通道扫描连续、间隔转换。

**Q5.** DMA（直接内存访问）是硬件设备直接访问内存、不经 CPU 介入的数据搬运技术。作用是外设与内存间直接传数据，节省 CPU 资源、提高效率。

**Q6.** 方向：外设→内存、内存→外设、内存→内存。每通道 3 个事件标志：半传输、传输完成、传输出错。数据宽度：字节(8)/半字(16)/全字(32)，GPDMA 有 16 个通道。

**Q7.** DMA_CPARx（外设地址）、DMA_CMARx（存储器地址）、DMA_CCRx（方向）、DMA_CNDTRx（数据量）。增量模式：每次传输后地址递增；循环模式：传输完成后回到起始地址重复搬移。

## 八、PCB 基本元器件与要点

**Q1.** 限制电流、调节电压与电流、保护电路。阻值取决于材料、长度、横截面积。

**Q2.** 电压不突变、阻碍电压变化，通交隔直，可用于滤波。单位法拉（F），常用 mF、μF、nF、pF。

**Q3.** 时钟系统必用，提供时钟基准；烧录、供电、复位是电路的基础。

**Q4.** 都可用作开关。三极管为电流驱动，MOS 管为电压驱动。

**Q5.** LDO（低压差线性稳压器）纹波小、电路简单，但效率较低（压差大时发热）；DC-DC（开关电源）效率高、可升压降压，但纹波较大、电路较复杂。

## 九、WIFI（ESP8266 / AT 指令）

**Q1.** 安信可 WIFI 模组，UART-WiFi（串口转 WIFI）。固件是用户不能修改、靠发送指令控制的代码，可烧写更新。

**Q2.** GPIO0 低电平 = 下载模式（下载固件）；高电平 = 运行模式（通信）。

**Q3.** 每条指令必须以 \r\n 结尾。

**Q4.** AT（检测）、AT+RST（复位）、AT+CWMODE（设 WIFI 模式）、AT+CWJAP（连热点）、AT+CIPSTART（连 TCP 服务器）、AT+CIPSEND（发送数据）。

**Q5.** 0 无 WiFi 模式；1 Station 模式（连其他热点）；2 SoftAP 模式（自身成为热点，只能发射不能联网）；3 SoftAP+Station 混合模式。

**Q6.** 连热点 `AT+CWJAP="热点名称","热点密码"`；连 TCP 服务器 `AT+CIPSTART="TCP","IP地址",端口号`。

**Q7.** 1 连接超时、2 密码错误、3 找不到 AP、4 连接失败。

**Q8.** `AT+CIPMODE=1` 开启（=0 取消），`AT+CIPSEND` 进入透传，单独数据包 `+++` 退出。

## 十、FreeRTOS

**Q1.** 实时操作系统，按排序运行、管理系统资源。最大特色是"实时性"——任务需要执行时能在较短时间内执行，无较长延时。

**Q2.** 裸机单线程（main 循环+中断）、无调度器、一次一件事、开销小；RTOS 多任务、有调度器按优先级/时间片抢占调度、宏观并行微观快速切换、提供同步机制、有内核开销。

**Q3.** 抢占式调度针对优先级不同的任务（高优先级就绪立刻抢占 CPU，只有高优先级阻塞/挂起低优先级才运行）；时间片调度针对优先级相同的任务（轮流运行，每个任务跑 1 个时间片 1ms）。

**Q4.** 滴答是硬件定时器按固定频率产生的中断，是时间基准，本质是 Cortex-M 内核的 SysTick。configTICK_RATE_HZ 决定滴答频率，一般 1000Hz（1ms 一次）。

**Q5.** 运行态（获得 CPU 使用权被实际执行）；就绪态（已能执行但未被执行）；阻塞态（因延时或等待外部事件，有超时时间）；挂起态（vTaskSuspend 进入、vTaskResume 退出，不能被运行）。

**Q6.** 创建 `osThreadNew(func, argument, attr)` 返回句柄；挂起 `vTaskSuspend(句柄)`（NULL 挂起自身）；恢复 `vTaskResume(句柄)`；删除 `osThreadTerminate(句柄)`。

**Q7.** 调度器启动（vTaskStartScheduler）时自动创建，优先级最低（0）。作用：无其他任务运行时维持系统运作、资源维护（清理内存）、节能调度（触发休眠）、通过空闲钩子函数扩展。
