### 第4题（指针与数组）
```c
int *p = a;           // p指向数组首元素
printf("%d\n", *(p + 2));  // p+2跳过2个int，指向a[2]=30
```
或者 `printf("%d\n", p[2]);`

### 第5题（函数参数传递）
C语言函数参数是**值传递**。swap函数中的x和y是实参的**副本**，函数内部交换的是副本的值，实参不受影响。要交换实参的值，需要传指针：`void swap(int *x, int *y)`，函数内用 `*x` 和 `*y` 操作。

### 第6题（字符串与\0）
返回5。strlen 计算字符串长度时遇到 `\0` 就停止计数，只统计 `\0` 之前的字符。"Hello" 共5个字符，所以返回5。"World" 虽然也在数组中，但被 `\0` 隔开了，strlen 不会统计它。

### 第7题（动态内存分配）
```c
void allocArray(int **p, int n)
{
    *p = (int *)malloc(n * sizeof(int));
}
```
二级指针 `int **p` 接收主函数指针变量的地址，通过 `*p` 修改主函数的指针，使其指向堆区新分配的空间。

### 第8题（顺序表插入）
必须**从最后一个元素开始向后移动**。如果从 post 位置开始向前移动，前面的元素会把后面的元素覆盖掉，导致数据丢失。从后往前移动可以保证每个元素先挪到后面的空位，不会互相覆盖。

### 第9题（链表遍历）
有头链表的头节点数据域无效，需要跳过。`p->next != NULL` 保证了p指向头节点时直接跳到下一个节点才开始遍历，当p指向最后一个有效节点时，p->next 为NULL，循环结束，正好打印完所有有效数据。

如果用 `p != NULL`，需要先 `p = p->next` 跳过空数据头节点，否则会多走一次循环访问到 NULL 导致段错误。

### 第10题（递归函数）
```c
int sum(int n)
{
    if (n == 1)      // 终止条件
        return 1;
    return n + sum(n - 1);  // 递归调用
}
```
终止条件：当 n == 1 时，直接返回 1，不再递归调用。

### 第11题（时间复杂度）
O(n log n)。推导过程：
- 外层 while 循环：i 从 1 到 n，执行 n 次
- 内层 for 循环：j 从 1 开始，每次 j += j（即 j *= 2），到 n 结束，执行次数为 log2(n) 次
- 总次数 = n * log2(n) => O(n log n)

容易误判为 O(n^2)，因为 j += j 的增长速度是指数级的，不能只看有几层嵌套，还要看每层的增长方式。

### 第12题（括号匹配）
算法步骤：
1. 遍历字符串的每个字符
2. 遇到左括号 `(`、`[`、`{`，将其入栈
3. 遇到右括号 `)`、`]`、`}`，先检查栈是否为空，为空则说明缺少左括号，不匹配；不为空则出栈栈顶元素，对比类型是否一致
4. 遍历完成后，检查栈是否为空。为空说明所有括号都匹配了；不为空说明有左括号没被匹配

对于 `({[()]})`：每个左括号都能找到匹配的右括号，且类型一致，遍历结束后栈为空 -> 匹配成功。
对于 `({[)]}`：遇到 `)` 时栈顶是 `[`，类型不匹配 -> 匹配失败。

### 第13题（双向链表）
**双向链表效率更高。** 已知节点指针 p 时：
- 双向链表：通过 `p->prev` 可以直接找到前驱节点，然后 `p->prev->next = p->next` 完成删除，O(1)
- 单向链表：只有 next 指针，无法直接找到前驱节点，需要从头遍历链表找到 p 的前驱节点，O(n)

### 第14题（二叉树叶子节点）
```c
int leafCount(bitree_p root)
{
    if (root == NULL)                     // 空树返回0
        return 0;
    if (root->lchild == NULL && root->rchild == NULL)  // 叶子节点：左右孩子都为空
        return 1;
    return leafCount(root->lchild) + leafCount(root->rchild);  // 非叶子：左右子树的叶子数之和
}
```

### 第15题（链表转置）
核心思想：**将原链表的每个节点依次取下来，用头插法插到头节点后面。**
将头节点的 next 置为 NULL 的原因：这相当于创建了一个空链表，然后依次把原链表的节点取下来头插到这个空链表中。第一个被头插的节点会成为新链表的最后一个节点（即原链表的第一个节点），依此类推，原链表的最后一个节点会成为新链表的第一个节点，实现逆序。
